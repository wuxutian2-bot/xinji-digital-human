# 心迹用户界面修订

用户指出三个问题：侧栏入口挤压、普通页面暴露运行说明、五个同级入口混合用户与评审任务。本轮直接修正现有界面，保留状态统计、支持偏好、反馈和行动的数据行为。

## 信息层级

- 聊天侧栏只放一个「我的心迹」入口：固定图标、横向标题与说明、进入箭头。
- 日常面板只有「记一记／看变化／小步骤」三个主入口。「记一记」先展示可选感受表单；趋势和周回顾在「看变化」。
- 查看、修改和删除旧记录由趋势页进入，提供明确返回；数据与隐私位于底部。未同意的体验档案首次载入时打开说明，保存同意后进入记录页。
- 普通页面使用「示例体验」标识，在历史区域注明示例记录。配置标签、规则决策、表达参数只在独立的 `?view=demo` 入口展示。
- 到访和回访事件按钮移至演示工作台的组织者工具。导航分离不是身份认证或权限隔离。

## 视觉与措辞

沿用纸白和浅绿，减少装饰性标题与运行术语。三个主入口等宽，不依赖横向滚动；记录管理不占一级导航。记录表单缩短纵向留白，让默认窗口中保存按钮可见。零分仍是有效记录，未填写显示「暂不记录／未记录」，不改统计规则。
