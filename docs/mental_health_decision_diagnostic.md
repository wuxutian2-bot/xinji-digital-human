# E3 独立 Decision 诊断

日期：2026-09-23。状态：E3a四组真实开发集诊断完成，结果与导出核对通过；E3b语义策略改进尚未开始。

## 问题与边界

E1 的两套 Dialogue 模型实验中，独立 Decision 在 R1 的正常原始提议均为 `supportive_listening`，部分正确最终策略由本机协调器覆盖得到。本轮定位原始提议为什么集中，不评估 Dialogue 文本、语音或临床收益，也不回填 E2 人工评分。

代码检查发现两处可能影响提议的输入：系统提示词使用含 `default` 的展示 schema；状态估计器输出 `current_state.interaction_strategy`，在低信号状态下是倾听默认值。真正约束生成的 schema 已经剔除了默认值；因此不能把提示词中的默认值和解码语法混为一谈。

## 冻结实验

`tests/fixtures/decision_diagnostic_cases.json` 是本轮新增的10个虚构开发场景：倾诉/拒绝建议、明确求助、结束、理清问题、强烈不适、有效历史、陈旧历史、未知历史、协议控制输入、高风险绕过。标签和理由在模型调用前冻结，只有评估器能看到，未送给模型。

| 变体 | 提示词 schema 默认值 | 状态策略标签 | 生成约束 |
|---|---|---|---|
| baseline | 保留 | 保留 | 相同完整 schema |
| no_schema_defaults | 移除 | 保留 | 相同完整 schema |
| no_state_strategy | 保留 | 移除 | 相同完整 schema |
| both | 移除 | 移除 | 相同完整 schema |

四组均通过实际生产 Decision 客户端构建请求、解析输出，再执行同一本机协调器；消融只在实验的请求转发层执行。温度0、请求 seed 20260923、上限300 token、总期限15秒、禁用 SDK 重试。服务为既有 Qwen2.5-1.5B-Instruct Q4_K_M / llama.cpp b10964 CPU，模型和服务二进制哈希记录在 manifest。

每组三次重复，每次10个场景，合计120个场景运行；实际108次正式请求全部合法，另2次预热合法且单独保存。12次高风险场景均为零模型调用。每个重复内随机交错四组，以减少顺序偏差。固定seed和相同虚构案例的重复并不产生独立统计样本。

历史对照使用完全相同的当前文本，分别提供可用的跨日高压力、30天前陈旧记录或空历史；均由实际 daily_v2 生成模型输入。三个历史案例允许倾听或澄清，不把策略必须变化写成“正确答案”。本批只能检查历史表示是否送达和是否出现不适当策略，不能凭策略相同断言模型完全忽略历史。

## 实际结果

| 变体 | 原始模型提议匹配 | 协调后匹配 | 原始提议的主要不足 |
|---|---:|---:|---|
| baseline | 18/27 | 27/27 | 求助、结束、澄清各0/3 |
| no_schema_defaults | 20/27 | 27/27 | 求助与结束各0/3，澄清2/3 |
| no_state_strategy | 17/27 | 27/27 | 求助、结束、澄清各0/3，倾诉退化1次 |
| both | 22/27 | 27/27 | 求助0/3、结束1/3、澄清3/3 |

全部正式请求无截断或回退，108次有效请求变更边界检查通过。逐例见 `logs/evaluation/e3-factorial-20260923-export/summary.md`。36个“案例×变体”组中三次实际请求内容完全一致，但部分输出仍波动，因此仅声明请求seed相同，不声明位级确定性。源码和样例运行前后哈希一致。

**可以得出的结论：** 原始输出与解析后的策略一致，未发现解析器将多样策略改写为倾听。当前生产提示词可以在强烈不适案例中提出安抚稳定，因此“所有情况下只能输出倾听”不成立。去掉默认值和状态策略标签改善了本批澄清选择，但单独去掉状态策略反而造成一次倾诉退化；两者不是所有语义失败的唯一原因。明确求助在四组中均没有命中，仍需继续处理诉求到策略的语义映射。

**本轮决策：** 不把开发集22/27当作修复完成，不改生产客户端或默认配置。下一批E3b在实验入口制作更简明的策略选择契约，特别明确求助、拒绝建议、结束和澄清的边界；与当前基线及both候选比较，完成开发阶段后冻结版本，再另建保留样例一次验证。原始失败保留，不用本机协调后的27/27替代模型能力指标。

## 结论更新规则

先保存四组完整结果，再判断是否存在可定位的最小修复。部分场景改善必须连同退化场景报告；仅开发集改善时不能声称泛化或开启默认模型。独立 Decision 的启用门槛仍需要新的保留集与真实对话质量评价。E1 的冻结报告和 E2 空白评阅表继续保留。
